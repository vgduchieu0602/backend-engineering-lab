# Variable declaration

Trong JS, let và const được dùng để khai báo variable

## Let

let được dùng khi variable cần được reassigned

## Reassignment

Reassignment là việc gán 1 value mới cho 1 variable đã tồn tại

## Const

const được dùng khi variable không cần được reassigned
